CÁCH DÙNG NHANH

1) Tạo tài khoản GitHub miễn phí.
2) Tạo repository public mới, ví dụ: oishi-ar
3) Upload toàn bộ nội dung folder này lên repository:
   - index.html
   - assets/model.glb
4) Vào Settings -> Pages
5) Chọn Deploy from a branch
6) Chọn main và /(root), rồi Save
7) Website sẽ có dạng:
   https://USERNAME.github.io/oishi-ar/
8) Dùng link đó để tạo QR.
9) Người dùng quét QR -> mở web -> bấm “XEM TRONG AR”.

Lưu ý:
- Android thường dùng Scene Viewer.
- iPhone thường dùng Quick Look.
- Nếu model có animation phức tạp, iPhone có thể cần file USDZ riêng để tối ưu hơn.
